# Seedance 2.0 提示词规范

> 平台参数与界面文案可能更新;生成前以当前平台实际选项为准。以下为 2026-11 的通用规范。

## 一、能力与限制

- **模式**:文生视频 / 图生视频(首帧,可选尾帧)/ 参考生视频。
- **参考素材**:最多 12 个文件——9 张图片、3 段视频、3 段音频;视频/音频参考各自总时长 ≤15 秒。
- **时长**:单条 4–15 秒。
- **画幅**:9:16(本项目固定)。
- **分辨率**:480p(草稿)、720p(社交发布)、1080p(交付)、4K(大屏)。
- **音频**:支持原生音频;本项目建议只生成环境音/动作声,台词与 BGM 后期铺。
- **人物限制**:不支持真实人脸素材;本项目本来就不出现人类正脸。

## 二、提示词公式

**工程公式**:

> 精准主体 + 动作细节 + 场景环境 + 光影色调 + 镜头运镜 + 视觉风格 + 画质 + 约束条件

**六段式**(更好记):

> 主体 → 动作 → 场景(地点、时间、光线、天气)→ 运镜(景别、推拉、跟随)→ 风格 → 声音

**写法要求**
- 一条提示词只写一个主要动作。
- 场景写具体:地点、时间、光线方向、天气、材质。
- 运镜写一个主要动作,不要叠加推、拉、摇、移。
- 风格写 2–3 个词:真实手机 vlog、自然光、浅景深、细腻颗粒。
- 结尾写约束:保持毛色/眼睛/爪子/尾巴;无人类、无字幕、无水印、无 Logo。

## 项目视觉风格锚点(本项目强制)

每条提示词必须带风格底色 A,再按镜头选 B 或 C。完整拆解见 `visual-style.md`。

- **A 全片底色**:电影级写实摄影,真实光线,暖金色高光与冷蓝色阴影,真实毛发与材质细节,空气透视,细腻胶片颗粒,高动态范围,治愈系旅拍质感,9:16 竖屏,画面无文字、无水印、无 Logo。室内用室内实用光源 + 窗外自然光;户外用黄金时刻侧逆光。
- **B 大景构图(旅居/出发/到达)**:黄金时刻低角度侧逆光;天地辽阔,芋仔小小一只位于画面下三分之一,上方留出天空与远山;24mm 广角,低机位,深景深,电影级风光摄影,主体清晰。
- **C 中近景/特写(办公室/眼神/爪子)**:浅景深,低机位,主体清晰,背景保留环境层次;室内实用光源与窗外自然光混合,暖冷对比,真实毛发与材质,安静克制,细腻胶片颗粒。

组合:角色锚点 + 镜头内容 + A + (B 或 C)+ 负面约束。一条提示词只选 B 或 C。

## 三、主体定义与参考图映射

**标准写法**:

> 将图片1中的布偶猫芋仔(奶油白长毛、耳朵与面部灰褐色重点色、明亮蓝眼睛、白色爪子、蓬松大尾巴)定义为<主体1>。

**参考映射**:
- `@图片1` 作为角色形象参考
- `@图片2` 作为场景参考
- `@图片3` 作为首帧
- `@图片4` 作为尾帧
- `@视频1` 参考运镜方式
- `@音频1` 用于配乐/对白参考

**注意**
- 不要把整张三视图直接当角色参考——多视图可能被模型理解成多只猫。从三视图里裁出单张正脸、单张全身,分别上传。
- 多张图指向同一只猫时,用稳定特征绑定成一个主体;不要给同一只猫起多个标签。
- 一帧只出现一只芋仔;在提示词里加一句「画面中只有一只猫」,避免复制。
- 参考素材不要塞满;推荐 4–5 个:1–2 张角色图、1 张场景图、1 段运镜参考、1 段音频。

## 四、图生视频规则

图生视频里,**图片已经确定了外貌**,提示词不要再描述一遍长相。只写三件事:

1. **运动**:谁,做什么,从什么状态到什么状态。
2. **运镜**:一个主要运镜。
3. **保持项**:保持毛色、眼睛颜色、白爪、尾巴形态;不要换背景;不要加物体。

**模板**:

> 以@图片1 为首帧,{主体}从{开始状态}到{结束状态};{一个运镜};保持毛色、蓝眼睛、白爪、蓬松尾巴不变;{光线/风格};画面中只有一只猫;无人类、无字幕、无水印。

**首尾帧**:起止画面明确时用 `@图片1 作为首帧,@图片2 作为尾帧`,中间运动写"缓慢、连续、不间断"。

## 五、多镜头语法

- 用「镜头1 / 镜头2 / 镜头3」按事件顺序写,不要写精确到秒的时间戳。
- 每个镜头包含:运镜或剪辑方式 → 主体动作与表情 → 位置/空间变化 → 声音。
- 节奏用相对词:快速、缓慢、随即、片刻后、定格一瞬。
- 总时长在平台面板里选,并在提示词末尾加一句「时长 N 秒,9:16 竖屏,画面无字幕」。
- 本项目一镜一生成,通常不需要多镜头;需要一镜内转场时才用。

## 六、声音语法

- 对白:`{台词}`,并注明说话者;台词用中文,一句话说完。
- 音效:`<脚步声>`、`<纸箱摩擦>`、`<雨声>`。
- 音乐:`(轻柔钢琴)`。
- 字幕:`【字幕内容】`——本项目建议画面无字幕,字幕后期加,提示词里写「画面无字幕」。

## 七、运镜词汇

| 词 | 用法 |
|---|---|
| 固定机位 | 对话、观察、氛围;最稳 |
| 缓慢推近 | 强调情绪或细节 |
| 缓慢拉远 | 收尾、留白 |
| 平稳横移 | 展示空间 |
| 跟随 | 猫行走、移动 |
| 环绕 | 展示体积,但猫的环绕容易变形,慎用 |
| 低机位 | 猫视角、地面动作 |
| 手持 | 真实 vlog 感;幅度要小 |

一条提示词只选一个。猫的镜头优先固定、缓推、低机位跟随;环绕和快速运镜容易让毛发和爪子变形。

## 八、负面约束(芋仔专用,每镜追加)

> 人类正脸,人类身体,多只猫,毛色改变,眼睛颜色改变,穿衣服,多余肢体,畸形爪子,多趾,尾巴分叉,文字,字幕,水印,Logo,卡通渲染,塑料感,背景替换,画面剧烈抖动

## 九、抽卡策略

1. 先 480p、5 秒、低分辨率抽 2–3 条,确认角色和动作方向。
2. 每次只改一个变量:动作幅度、运镜、光线、参考图。
3. 动作最稳的那条再出 720p/1080p。
4. 单镜重试 ≤3 次;3 次不成,降低动作难度或改分镜。
5. 先做关键动作镜头(行走、摸头、抬头),再做氛围镜头。

## 十、单镜提示词块模板

```
### 镜 {N}｜{时长}
- 模式:{图生视频首帧 / 首尾帧 / 参考生视频 / 文生视频}
- 参考:{@图片1 角色;@图片2 场景;@图片3 首帧;…}
- 提示词:{主体定义}。{动作:从…到…}。{场景:地点、时间、光线}。{一个运镜}。{风格:真实 vlog、浅景深、自然光}。保持毛色、蓝眼睛、白爪、蓬松尾巴不变;画面中只有一只猫;无人类、无字幕、无水印。
- 参数:9:16,{时长}s,{480p 草稿 / 720p 成片}
- 负面:{芋仔专用负面约束}
- 备注:{重试重点/替代方案}
```

## 十一、完整示例

**镜 1｜4s｜图生视频(首帧)**

## Seedance 2.5 30 秒单条(火山引擎)

Seedance 2.5 支持单段 30 秒直出;提示词按四段式写:

1. **素材绑定**:按上传顺序给图片/视频/音频编号,写清各自负责什么。
2. **一句话概述**:主体 + 地点 + 事件 + 风格 + 特殊镜头。
3. **时间戳分镜**:连续整数秒,如 0–3、3–8、8–14,30 秒闭合;每镜写景别/机位/运镜 + 动作/表情 + 台词(角色) + 音效。
4. **全局约束**:画幅、光线、色彩、一致性、排除项。

参考图注意:三视图是同一只猫的三个角度,不是三只猫;只取外观,不继承分格排版、灰底、图上文字;画面中只出现一只猫。能裁成"正面脸 + 全身"两张更稳。结尾留 2 秒黑场,片尾卡后期加。

## 十二、常见问题与修复

| 问题 | 修复 |
|---|---|
| 角色长相漂移 | 用单张正脸 + 单张全身做参考;提示词重复固定锚点;不要用整张三视图 |
| 多出一只猫 | 提示词加「画面中只有一只猫」;减少参考图数量 |
| 爪子畸形 | 避免爪子特写和复杂动作;改成静帧或实拍手部 |
| 毛色/眼睛变了 | 提示词明确"保持奶油白长毛、蓝眼睛";负面词加上 |
| 运镜没执行 | 把运镜词放到提示词更靠前的位置;只保留一个运镜 |
| 动作太复杂做不出来 | 拆成两个镜头;或改成"从静止到轻微移动" |
| 画面出现文字 | 负面词加"文字、字幕、水印、Logo";提示词写"画面无字幕" |
| 人类正脸出现 | 负面词加"人类正脸";分镜阶段就不要写人类脸 |
