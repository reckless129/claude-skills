# 故事类型与节拍模板

阶段 0 先定类型;阶段 2 用对应节拍模板;阶段 4 的分场节拍从同一模板派生。

**30 秒首版**:取对应类型的前四拍 + 片尾卡;中段节拍合并,不新增类型。第一次试做优先走这个长度。

## 快速选择

| 本集素材 | 类型 |
|---|---|
| 一个地方、一个瞬间、没有强冲突,想给情绪 | A 治愈日常型 |
| 有一个具体障碍:雨、水、楼梯、陌生人、迷路、食物 | B 旅途冲突型 |
| 另一个角色出现:猫、人、狗;涉及边界 | C 社交成长型 |
| 回望、纪念日、旧物、阶段总结 | D 独白回忆型 |
| 需要观众参与:投票、二选一、下一站 | E 互动征集型 |

如果同时满足两类:按**本集情绪落点**选。落点是安慰 → A;紧张后的松弛 → B;关系变化 → C;领悟 → D;参与 → E。

---

## A · 治愈日常型(默认)

- **适用**:一个地方、一个瞬间,没有强冲突。
- **情绪目标**:被轻轻安慰。
- **节拍**:

| 节拍 | 时长 | 必须发生的事 |
|---|---|---|
| ① 钩子 | 0–4s | 一句话立住处境或反差 |
| ② 处境 | 4–12s | 一个可看的日常细节 |
| ③ 小事件 | 12–22s | 一个轻微变化:风、阳光、食物、声音 |
| ④ 猫性动作 | 22–34s | 晒太阳 / 馋 / 好奇 / 纸箱 / 帽子 |
| ⑤ 情绪落点 | 34–46s | 一句替观众说出口的话 |
| ⑥ 片尾卡 | 46–52s | 辞职第 N 天 / 电量 / 下一站 |

- **镜头模式(6–8 镜)**:全景建立 → 细节 → 动作 → 反应特写 → 留白 → 卡
- **例**:大理,民宿阳台,全世界最好的工位。

---

## B · 旅途冲突型

- **适用**:天气、水、楼梯、陌生人、迷路、食物等具体障碍。
- **情绪目标**:紧张一下,再松一口气。
- **节拍**:

| 节拍 | 时长 | 必须发生的事 |
|---|---|---|
| ① 钩子 | 0–4s | 把障碍摆出来 |
| ② 意外 | 4–12s | 障碍发生,计划被打断 |
| ③ 退缩/反应 | 12–20s | 芋仔的第一反应:躲、停、看 |
| ④ 被迫面对 | 20–32s | 一个外部原因迫使它前进 |
| ⑤ 小转折 | 32–44s | 它用自己的方式解决或接受 |
| ⑥ 落点 + 卡 | 44–52s | 一句不煽情的总结,进片尾卡 |

- **镜头模式(7–9 镜)**:建立 → 破坏 → 反应特写 → 尝试 → 结果 → 留白 → 卡
- **例**:被一场雨困在古镇,怕雨的芋仔听了三小时雨声。

---

## C · 社交成长型

- **适用**:另一只猫、人、狗出现;涉及试探、边界、被欺负。
- **情绪目标**:替它紧张,也为它高兴。
- **节拍**:

| 节拍 | 时长 | 必须发生的事 |
|---|---|---|
| ① 钩子 | 0–4s | 他者出现,或关系悬念 |
| ② 遇到他者 | 4–12s | 距离、视线、第一次接触 |
| ③ 试探 | 12–20s | 芋仔靠近一小步 |
| ④ 翻车/退缩 | 20–30s | 被吓到、被挤到最后、说不出话 |
| ⑤ 第二次尝试 | 30–42s | 它换了一种方式 |
| ⑥ 微小进步 | 42–50s | 关系移动了一点点,不解决全部 |
| ⑦ 落点 + 卡 | 50–56s | 一句自觉,不总结道理 |

- **镜头模式(8–9 镜)**:双人/双猫 → 反应 → 撤退 → 回来 → 细节变化 → 留白 → 卡
- **例**:本地猫来收保护费,芋仔交出了半块小蛋糕。

---

## D · 独白回忆型

- **适用**:纪念日、旧物、阶段总结、现在与过去的对比。
- **情绪目标**:安静地被打动。
- **节拍**:

| 节拍 | 时长 | 必须发生的事 |
|---|---|---|
| ① 钩子 | 0–4s | 现在的一个动作,带出旧物 |
| ② 旧物/旧画面 | 4–14s | 一个可插入的静帧或旧场景 |
| ③ 现在对比 | 14–26s | 同一个动作,现在不一样了 |
| ④ 一个动作 | 26–38s | 芋仔做一个小的、具体的动作 |
| ⑤ 领悟 | 38–48s | 一句短话,不解释 |
| ⑥ 落点 + 卡 | 48–56s | 片尾卡 |

- **镜头模式(6–8 镜)**:现在 → 插入静帧 → 现在细节 → 特写 → 全景 → 卡
- **例**:辞职一个月,我想对工位上的自己说句话。

---

## E · 互动征集型

- **适用**:下一站投票、A/B 选择、粉丝互动。
- **情绪目标**:想参与。
- **节拍**:

| 节拍 | 时长 | 必须发生的事 |
|---|---|---|
| ① 钩子 | 0–4s | 把选择摆出来 |
| ② 两个选项 | 4–16s | 两个目的地/道具/画面 |
| ③ 猫的反应 | 16–28s | 芋仔对两个选项的不同反应 |
| ④ 犹豫/选择 | 28–40s | 它做出一个小动作,但不给答案 |
| ⑤ 投票引导 | 40–48s | 字幕邀请观众决定 |
| ⑥ 片尾卡 | 48–52s | 片尾卡 |

- **镜头模式(6–7 镜)**:选项 A → 选项 B → 猫反应 → 犹豫 → 字幕卡 → 卡
- **例**:下一站去哪?你们说了算。

---

## 类型使用规则

1. 一集只用一个主类型;可以借用其他类型的单个节拍,但不能混两套结构。
2. 阶段 2 的节拍表必须逐条对应模板;删改节拍要说明理由。
3. 阶段 4 把每个场景拆成 2–4 个节拍,节拍必须让信息或情绪发生变化。
4. 总时长 50–65 秒;类型模板的时长是默认值,可按内容微调,但不能超过 65 秒。
