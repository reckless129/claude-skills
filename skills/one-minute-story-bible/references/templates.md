# 阶段输出模板

## 阶段 0 · 立项卡

```
【阶段 0 · 立项卡】
- 集数:EP{NN}
- 工作标题:{一句话标题}
- 故事类型:{A 治愈日常 / B 旅途冲突 / C 社交成长 / D 独白回忆 / E 互动征集}
- 目的地:{城市/场景}
- 目标时长:{50–65 秒}
- 情绪核心:{观众看完应该产生的那一种情绪}
- 观众带走的一句话:{本集的金句方向,不是最终台词}
- 本集使用的真实梗:{从故事圣经里选,没有就写"无"}
- 约束:无人类正脸;≤9 镜;仅关键镜头图生视频;480p 草稿;AIGC 标识

请确认:这个立项对吗?要改哪一项?
```

## 阶段 1 · 故事脊柱

```
【阶段 1 · 故事脊柱】
- Logline:{谁,想要什么,被什么挡住,结果如何}
- 主角想要:{具体目标}
- 阻碍:{具体障碍}
- 转折:{它做了什么改变}
- 结尾画面:{一个可拍的画面,不是道理}
- 观众带走的一句话:{情绪落点}
```

## 阶段 3 · 完整剧本

按 `script-standard.md` 的场景块逐场输出:

```
## 场景 {N}｜{时间}·{地点}
- 时长:{0:00–0:xx}
- 出场:{芋仔 / 手部 / 无}
- 画面:{开始状态 → 结束状态}
- 台词/旁白:{角色,画外/画内}:"{台词}"
- 声音:{环境音 / 音效 / BGM}
- 连续性:{道具、光源、角色状态}
- 制作备注:{图生视频 / 静帧+运镜 / 实拍手部 / 模板}
```

## 阶段 6 · Seedance 提示词

每镜一块:

```
### 镜 {N}｜{时长}
- 模式:{图生视频首帧 / 首尾帧 / 参考生视频 / 文生视频}
- 参考:{@图片1 角色;@图片2 场景;…}
- 风格锚点:{A 全片底色 + B/C 构图变体,来自 visual-style.md}
- 提示词:{主体定义}。{动作:从…到…}。{场景}。{一个运镜}。{风格锚点 A+B/C}。保持毛色、蓝眼睛、白爪、蓬松尾巴不变;画面中只有一只猫;无人类、无字幕、无水印。
- 参数:9:16,{N}s,{480p 草稿 / 720p 成片}
- 负面:{芋仔专用负面约束}
- 备注:{重试重点/替代方案}
```

## 阶段 7 · 交付包

```
【交付包】
1. 剧本:{链接或全文}
2. 分镜表:{链接或全文}
3. Seedance 提示词:{链接或全文}
4. 发布包:标题 3 个 / 封面文字 / 标签 / AIGC 标识
5. 未通过项:{逐条列出;没有就写"无"}
```

## 节点确认收尾(每个阶段必须使用)

```
【阶段 {N} · 等待确认】
本阶段产出:{一句话}
请你确认:
1. {需要用户拍板的具体点}
2. {需要用户拍板的第二个点}
回复「确认」进入阶段 {N+1};要改就直接说修改点。
```
