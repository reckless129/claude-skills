# 可影视交付的剧本标准

## 剧本头

```
# 《标题》
- 集数:EP{NN}
- 故事类型:{A/B/C/D/E}
- 总时长:{50–65 秒}
- 一句话(logline):{谁,想要什么,被什么挡住,结果如何}
- 主角:芋仔
- 地点:{城市/场景}
- 版本:v1.0
```

## 场景块(每个场景必须用这个格式)

```
## 场景 {N}｜{时间}·{地点}
- 时长:{0:00–0:12}
- 出场:{芋仔 / 手部 / 无}
- 画面:{只写看得见的东西;用现在时;一句一个动作}
- 台词/旁白:{角色,画外/画内}:"{台词}"
- 声音:{环境音 / 音效 / BGM 进出点}
- 连续性:{服装、道具、光源、角色状态、与前一场的衔接}
- 制作备注:{图生视频 / 静帧+运镜 / 实拍手部 / 模板}
```

## 示例场景

```
## 场景 1｜深夜·办公室
- 时长:0:00–0:12
- 出场:芋仔
- 画面:深夜办公室,只亮半排灯。芋仔趴在工位纸箱里,抬头看镜头。纸箱壁上贴着一张磨旧的「员工编号 007」。
- 台词/旁白(芋仔,画外):"我是芋仔,这家公司的编外人员——招财猫。"
- 声音:空调低鸣、键盘声。键盘声在第 10 秒渐弱。
- 连续性:芋仔不背背包;纸箱在工位右侧;光源为冷白日光灯 + 屏幕光。
- 制作备注:图生视频,轻微抬头;其余为静帧 + 缓推。
```

## 硬标准

1. **总时长 50–65 秒**。场景数 3–6 个;每场 5–20 秒。
2. **每句台词有说话者**;画外音标「画外」。没有台词的镜头写「无」,不要留空。
3. **只写可见、可听的东西**。心理活动写成旁白或可见行为,不写"它感到孤独"这种拍不出来的句子。
4. **不用模糊词**:一些、之类、等等、差不多、适当。要么写具体数量/动作,要么删掉。
5. **人类不出现脸和身体**,最多手部;需要人类存在感时,用空镜、背影以外的声音或物品(键盘、外套、灯开关)代偿。
6. **每个场景必须有连续性和制作备注**。没有这两项,视为未交付。
7. **台词能念出来**:每句控制在 25 字以内;长句拆成两句,句间留半拍。
8. **结尾必须落在画面上**,不是道理。最后一句台词后面要有一个可拍的收尾动作。

## 交付前自检

- [ ] 总时长相加等于 50–65 秒
- [ ] 每个场景有地点、时间、时长、画面、台词、声音、连续性、制作备注
- [ ] 每句台词有说话者
- [ ] 没有人类正脸/身体
- [ ] 没有"一些/之类/等等"等模糊词
- [ ] 最后一句台词后有一个可拍的收尾动作
- [ ] 片尾卡字段齐全:辞职第 N 天 / 电量 XX% / 下一站:XX
- [ ] 没有解释电量怎么充、怎么减
