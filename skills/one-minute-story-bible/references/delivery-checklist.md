# 交付质检清单

完成阶段 6 后逐项检查;任何一项不通过,回到对应阶段修改,不要带着问题交付。

## A. 故事

- [ ] 故事类型明确(A–E),且节拍模板与类型匹配
- [ ] Logline 说清:谁、想要什么、被什么挡住、结果如何
- [ ] 每场戏至少有一个变化(信息/情绪/关系)
- [ ] 结尾落在一个可拍的画面上,不是道理
- [ ] 没有新增未确认的世界观设定

## B. 剧本

- [ ] 总时长 50–65 秒;场景数 3–6
- [ ] 每个场景有地点、时间、时长、画面、台词、声音、连续性、制作备注
- [ ] 每句台词有说话者;画外音标注
- [ ] 没有"一些/之类/等等/差不多"等模糊词
- [ ] 台词是芋仔的声音:第一人称、短句、不煽情、不讲道理
- [ ] 没有"浪费时间"这类直白说教
- [ ] 人类不出现正脸和身体,最多手部

## C. 分镜

- [ ] 镜头数 ≤9
- [ ] 30 秒首版:总时长 28–32 秒,镜头 6–7,图生视频 ≤2
- [ ] 每镜 2–8 秒;总时长相加 50–65 秒
- [ ] 每镜一个主要动作、一个主要运镜
- [ ] 每镜有开始状态和结束状态
- [ ] 图生视频镜头 ≤3
- [ ] 每镜有台词/字幕或声音设计
- [ ] 片尾卡:辞职第 N 天 / 电量 XX% / 下一站:XX

## D. Seedance 2.0 提示词

- [ ] 每镜一条提示词,与分镜镜号一一对应
- [ ] 每镜标明模式(首帧/首尾帧/参考/文生视频)
- [ ] 参考图映射清楚(@图片1、@图片2…)
- [ ] 图生视频提示词只写运动/运镜/保持项,没有重复描述参考图外貌
- [ ] 每镜有主体定义、动作、场景、运镜、光线、风格、时长、画幅
- [ ] 每镜追加芋仔专用负面约束
- [ ] 每条提示词带视觉风格底色 A
- [ ] 大景镜头用 B,特写用 C,没有混用
- [ ] 写实电影感,不是卡通/插画/3D 渲染/塑料感
- [ ] 暖金高光 + 冷蓝阴影;9:16 竖屏;画面无文字/水印/Logo
- [ ] 一镜只有一个主要动作、一个主要运镜
- [ ] 先生成 480p 草稿;单镜重试 ≤3 次

## E. 角色一致性

- [ ] 明亮蓝眼睛
- [ ] 耳朵与面部灰褐色重点色
- [ ] 白色爪子
- [ ] 蓬松大尾巴
- [ ] 奶油白长毛
- [ ] 背包只在旅居出发/行走镜头出现
- [ ] 不穿衣服;四足形态
- [ ] 画面中只有一只芋仔

## F. 合规与发布

- [ ] 发布时勾选 AIGC 内容标识
- [ ] 没有救助/领养类虚构情节
- [ ] 标题与封面不夸大、不造假
- [ ] 9:16 竖屏;字幕在底部安全区
- [ ] 抖音/小红书各自准备标题与封面
- [ ] 音乐来自平台曲库或有授权

## G. 流程合规

- [ ] 每个阶段都以「【阶段 N · 等待确认】」收尾
- [ ] 没有在一条消息里输出两个阶段的正式产出
- [ ] 没有把沉默当成确认
- [ ] 用户明确说「确认」后才进入下一阶段
